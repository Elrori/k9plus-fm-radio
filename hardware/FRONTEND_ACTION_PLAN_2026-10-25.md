# 96.8 MHz 接收弱：根因证据与实施方案

## 结论与证据边界

当前主要限制在模拟输入/1bit 转换形成的数据质量，既不是当前 UDP 丢包，也不是 I8 削顶。
不能仅由 1bit 数据区分：天线处本来就弱、板内噪声、LVDS 输入噪声、强信号硬限幅失敏。
95.987 MHz 强窄带信号是首要阻塞嫌疑，尚未通过移除它的 A/B 证明因果，也未确定内外来源。

实板把两个目标都放在 LO+200 kHz，分别接收5000包：

| 目标 | 200 kHz 内平均谱功率 / 邻近保护带中值 |
|---|---:|
|87.5 MHz|10.01 dB|
|96.8 MHz|1.42 dB|
|95.9866 MHz（与96.8同次采集）|20.07 dB|

这是总功率/估计噪底的代理值，不是减去噪声后的 SNR、SINAD 或 RF 输入功率。
节目变化、保护带占用和多径都会影响它。96 MHz 峰/邻近中值约47 dB/bin；不能与广播
FM 展宽信号的峰高直接比较。当前测量无丢包、无新增 FIFO 溢出、无 I8 削顶。
历史 overflow=30254228 是累计值，不应解释为当前没有历史故障。

新抓取 `build/dfe_20261025.k9raw` 为12003840个样本、0.050016秒，零丢包。
SHA256：DEB1D001B87E0BC3D4456F6F60A832F70E60B699575C14F07639D3AD6C52A150。
其中前20ms的同输入浮点筛选模型显示：I8量化误差比局部噪底低约30dB；新旧DFE在
靠近LO的96.8MHz没有明显改善（代理指标约0.96/0.80dB）。这不是不同时间的现场对比，
也不是RTL逐位模型。故当前不优先扩大UDP到I16，也不承诺DFE能治好96.8MHz。

## 第一阶段：可以直接实施的小改动

保留1.8k/1k分压、RF_P到VBIAS的1k、隔直1nF和串联100Ω。不安装100Ω差分终端。

1. 将RF_P到3.3V的现有1M电阻改为 `1M固定 + 1M多圈电位器` 串联。
   电位器滑臂与一个端点短接，当变阻器使用；初始设470k，即总值1.47M。
   比较器偏置大约从+2.11mV降为+1.44mV。此数值是电阻网络估算，不是最佳失调值。
2. 在RF_N/VBIAS处追加1nF C0G到地，现有100nF和1µF保留。三者靠近输入放置，
   接地短而宽。1nF改善高频旁路的效果需要实测；多电容与走线也可能存在反谐振。
3. 把前端集中到小铜板/接地平面，RF_P/N连接尽量小于1cm；不要通过长杜邦线传RF。
4. 拉杆放到离板卡至少0.5～1m的位置，用短同轴引回，屏蔽层接前端地；给拉杆底座
   提供约75cm回流导线或明确的地平面。比较前后时固定位置、长度、极化。

调门限：固定天线和环境，记录多个电阻位置下96.8的信道/局部噪底和听感，
选择实际最好点。可先以rf_ones接近0.5为粗调，但不能把0.5当作唯一验收标准。
`rf_ones`在NCO之前测量；数字调到空白频点不能给它制造“无信号输入”。
不要为了使占空比等于0.5增加很大的正反馈迟滞。

这一步成本低，可能改善偏置和自干扰，但没有依据承诺数dB以上的提升。

## 第二阶段：真正有机会改善弱台的RF模块链

建议接线（模块先按50Ω系统搭建/测量，不把拉杆当成精确50Ω信号源）：

```
拉杆/回流 → 同轴 → 87～109MHz带通预选 → 可旁路低噪声放大器
          → 0/3/6/10dB可切换衰减 → 原1nF C0G → 原100Ω → RF_P(C2)
                                                               |
                                                          原1k → VBIAS
RF_N(B2) → VBIAS；原1M+微调门限网络保留
```

模块验收要求（是采购/实测指标，不是未经验证的特定产品推荐）：

- 带通必须包含87.5MHz，目标87～109MHz插损≤2dB；在可能折叠到FM的132～153MHz
  尽量≥30dB抑制。明确端口阻抗及频响，不使用标为“FM陷波/广播抑制”的滤波器。
- 放大器起始增益约10dB，可旁路；NF目标≤2dB，有100MHz处的线性度数据。
  放大器供电按其规格，使用独立去耦；输出先隔直，不能把模块直流灌入FPGA。
- 增益从低往高试，每次记录信道/局部噪底。若仅整体变高而比例不改善，就停止加增益。
- 不在未知拉杆阻抗下直接照搬50Ω滤波器元件值；若DIY滤波器，先用VNA测插损与阻抗。

整段FM带通只能解决带外干扰，不能去除95.987MHz带内强信号。
如果没有带外问题，它的插损甚至可能使结果变差，因此保留旁路做A/B。

## 第三阶段：95.987MHz干扰的定性与针对性处理

先断电改线：在天线侧断开天线，用51Ω终端接RF入口地，保持隔直和比较器偏置。
再上电测95.987峰；输入噪声条件变化会改变1bit增益，因此这是定位线索，不是单次定论。
结合RSP1在远离板卡的位置观察同一频率：

- 终端后仍有强峰、靠近板卡明显增强：先排查板内时钟、电源和布线耦合，改善接地、
  屏蔽、天线距离。天线入口滤波不能消除从滤波器之后直接耦入的干扰。
- 外部也有同频强峰且天线接入明显增强：再考虑目标台预选或95.987MHz专用陷波。

近邻滤波的验收指标：目标95.987MHz额外抑制≥15～20dB，96.7～96.9MHz插损≤2dB，
有可旁路A/B。这比“看96MHz峰变低”严格，因为峰低可能只是所有信号一起变低。
通常需要高Q、多谐振器/螺旋或其他专门结构以及仪器调试。

不要直接加100nH+27pF并声称能解决近邻阻塞：该LC谐振在约96.9MHz，接近目标台；
即使精确调到95.987，普通器件Q也可能同时重伤96.8。仅0.813MHz的间距使选择性非常苛刻。
若无法实现上述指标，继续堆普通LC不如使用多位ADC/混频中频接收结构。

## 已实施的数字修改

HDSDR支路：`240MS/s → CIC3 /20 → 12MS/s → 63tap对称补偿FIR /2 → 6MS/s I8/Q8`。
960kS/s FPGA音频支路不变。UDP版本仍为2，flags bit2表示补偿DFE，原ExtIO可以接收。
Python显示器据此不再重复施加旧CIC补偿；新ExtIO声明有效带宽4.8MHz。

- ±2.4MHz通带计算误差小于0.002dB（不含模拟前端和量化）。
- 第二次抽取的3.6～6MHz阻带小于−84dB。
- 第一段CIC已造成的折叠不能由后级FIR消除：±2.4MHz通带内最差相对抑制仍约36dB。
  不能把−84dB写成整个接收机的抗混叠能力。
- 保持中心增益与旧版相同；没有用数字增益冒充信噪比改善。

验证命令：`./sim_wide.ps1`、`./sim_iq.ps1`、`./build.ps1`。
同输入筛选：`python tools/compare_wide_dfe.py build/dfe_20261025.k9raw`。
FIR仿真以独立整数卷积验证512个复数输出，包含脉冲、满幅、随机及输入间隔变化。
旧位流备份在`build/pre_dfe_20261025/`，可用`program.ps1 -Bit`指定回退。

ExtIO DLL已重新编译到`ExtIO/Release/ExtIO_K9Plus_FM_6M.dll`；未替换正在运行的
HDSDR进程中的DLL，旧DLL可直接接收新DFE数据。

- 新BIT SHA256：49A2A9B512FF0E9C786B461674665975EB0B86A90BFBE3C978EE6BAC00569C15。
- 完整布线WNS=+0.082ns、WHS=+0.013ns，时序满足；DRC零错误。
- 使用7593 LUT、9388 FF、102 DSP；本版为改善宽带滤波付出了较多DSP资源。

- 96.8实测5000包：flags=6，零丢包、零溢出、零削顶，I/Q范围−75～72。
  信道/局部噪底代理指标1.44dB；95.987强信号为19.24dB。

  96.8的1.42→1.44dB基本没有改善，与同输入离线筛选一致。

结果文件：`build/sim_wide/live_96p8.json`、`live_87p5.json`、`same_input.json`。
最终建议：保留该DFE作为宽带接收改进；若目标是显著提高96.8清晰度，应执行前端
定位/整改。未经比较器之前的测量或可旁路滤波A/B，不能把具体模拟根因写成已证实。
